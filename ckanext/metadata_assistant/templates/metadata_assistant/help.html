    {{ _('How the metadata assistant works') }}

    {{ _('The assistant helps you write better metadata. It suggests; you decide. Nothing is saved or published automatically.') }}

    {{ _('Two kinds of help') }}

    {{ _('The completeness check') }}
    {{ _('It runs by itself when you open the page and after you have changed a field, uses no AI and costs nothing. It points out what is missing or looks wrong: an empty recommended field, a very short description, a missing licence, a single keyword. "To fix" are gaps; "tips" are things that could be better.') }}
    {{ _('AI suggestions') }}
    {{ _('You press "Get AI suggestions". The AI reads your title, description, keywords and theme, and the landing page if you have given an address, and suggests better versions. It asks questions about what it cannot know. It takes a few seconds.') }}

    {{ _('What happens when you ask for AI suggestions') }}

    1. {{ _('If the dataset has a landing page address, the page is downloaded first. The AI uses it as a source of facts for the description. A copy is kept for some hours so that the page is not fetched again for every suggestion, and the panel says how old the copy is. If you know that the page has changed, press "Download the landing page again".') }}
    2. {{ _('The AI analyses the texts. When many people use the assistant at the same time, your request may wait in line; the panel shows your place.') }}
    3. {{ _('The suggestions appear, each next to the current value, with the changes marked in the text. You can edit a suggestion before you use it.') }}
    4. {{ _('You press "Use suggestion" for the ones you want. They are put into the form, not saved. Save the dataset as usual.') }}

    {{ _('What is sent to the AI service') }}

    {{ _('Only the title, description, keywords and theme, the landing page address and what was read from that page, the name of your organisation and of the catalogue, the catalogue\'s guidelines and what the completeness check found. Never data files, resources or personal data. The administrator chooses which AI service is used.') }}

    {{ _('Prepared suggestions') }}

    {{ _('An administrator can have suggestions prepared in advance for many datasets. When you open such a dataset they are shown at once, marked with the time ("Suggestions prepared 10:45"), without any waiting. They are valid until the texts change. Press "Get AI suggestions" for new ones.') }}

    {{ _('Good to know') }}

    • {{ _('The AI can be wrong. Read every suggestion; you are responsible for the metadata.') }}
    • {{ _('It never decides about confidentiality, personal data, licence or whether data may be published.') }}
    • {{ _('It does not remove facts from your description, and a suggestion identical to your text is not shown.') }}
    • {{ _('The name of a place the data is about can be a good keyword.') }}
    • {{ _('If something fails, the message says what to do. If it does not help, tell an administrator.') }}
